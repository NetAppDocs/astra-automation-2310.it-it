= Endpoint hook di esecuzione dell'API Astra (ACC)
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Crea e gestisci gli hook di esecuzione per le tue applicazioni. Ogni hook contiene configurazioni aggiuntive e fa riferimento a una sorgente di hook.

L'API Execution Hook consente una gestione semplificata degli hook di esecuzione. Gli hook di esecuzione contengono configurazioni aggiuntive e riferimenti a una risorsa sorgente dell'hook.
