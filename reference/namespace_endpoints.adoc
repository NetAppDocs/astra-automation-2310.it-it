[role="lead"]
Visualizza gli spazi dei nomi appartenenti a un cluster. Questi endpoint sono di sola lettura.

L'API Namespace fornisce accesso in sola lettura alle risorse namespace al fine di descrivere i namespace associati a un determinato cluster.
